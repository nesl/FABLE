# FABLE Runtime Prototype

This package contains the preserved provider catalog plus the first two implementation milestones:

- [Phase 0](README_PHASE0.md): shared contracts, identifiers, event-time utilities, provider-catalog adapter, and serialization fixtures.
- [Phase 1](README_PHASE1.md): authored semantic graph compiler, shared-graph hypothesis runtime, canonical bindings, frontiers/checkpoints, temporal guards, branch/fork handling, and scripted tests.

Run the current complete validation suite with:

```bash
python scripts/validate_phase1.py
```
