# Complex-event definitions

This directory contains the authored complex-event definitions used by the simplified FABLE language. Each `*.yaml` file says **what constitutes the complex event**, not which camera, provider, model, compute node, or network path should be used.

The language is documented in [`fable/language/README.md`](../fable/language/README.md).

Current definitions:

- `convoy`
- `robbery`
- `package_exchange`
- `drive_up_shooting`
- `repeated_visit`
- `rendezvous`
- `vehicle_convergence`
- `two_vehicle_chase`
